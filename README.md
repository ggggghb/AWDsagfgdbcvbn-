# منصة مساعد الذكاء الاصطناعي

واجهة عربية للمحادثة وتوليد الصور. تستخدم الواجهة وظيفة خادمية لإرسال الرسائل إلى Groq، لذلك لا يوضع مفتاح API في ملفات المتصفح.

## النشر على Vercel

1. استورد المستودع من GitHub إلى Vercel.
2. أضف متغير بيئة باسم `GROQ_API_KEY` في إعدادات المشروع، وضع فيه مفتاحاً جديداً من Groq.
3. أعد النشر بعد إضافة المتغير.

يجب تدوير المفتاح الذي سبق وضعه داخل ملف HTML، لأنه أصبح مكشوفاً. لا ترفع المفتاح الجديد إلى GitHub. وظيفة المحادثة في `api/chat.js` تحتاج استضافة تدعم وظائف Node.js؛ الاستضافة الثابتة مثل GitHub Pages لا تشغّلها.

قبل إتاحة الموقع للعامة، فعّل تحديد معدل الطلبات من إعدادات الحماية في Vercel لتقليل إساءة استخدام واجهة المحادثة.
